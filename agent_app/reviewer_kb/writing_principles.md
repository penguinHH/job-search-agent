# Writing principles for application materials

These apply to every language. The reviewer checks them in addition to grammar.

## 0. Non-negotiable
- **Facts only from the profile.** Every experience, number, date, title, publication, tool or result must be
  supported by the candidate profile. Anything not supported is a `fact` issue (severity high). The reviewer
  never invents facts in its suggestions either; if a claim must be weakened or removed, say so.
- Keep the candidate's real role: "built the environment and scripts; benchmark execution by a colleague" must
  not become "ran the benchmarks".
- No placeholders left in outgoing text (【要記入】, [TO FILL], ○○, XXX, "Company Name").
- Company name, person's name, position title and dates must be correct and consistent.

## 1. Cold / application email（応募メール・問い合わせメール）
- Subject states purpose + name: 「〇〇職への応募の件（東京大学 博士課程 許 明戈）」.
- Structure: 宛名 → あいさつ・名乗り → 結論（何の応募／何の問い合わせか）→ 根拠（相手に合う経験2〜3点、具体的な数字）→ 入社可能時期・条件（在留資格の変更が必要なこと等）→ 添付の案内 → 結び → 署名。
- Length: Japanese 400–800 characters; English 150–300 words. Longer is a `structure` issue.
- One clear ask (casual interview / application review / reply about openings).
- Company-specific: at least one sentence that shows the writer read the company's business or job post. Generic text that could be sent anywhere is a `content` issue.
- Signature: full name (kanji + romaji), affiliation, e-mail, phone.

## 2. Reply email（返信）
- Reply quickly and briefly; answer every question asked; confirm dates in full (2026年10月6日（火）11:00〜12:00).
- Keep the thread subject ("Re: …"); reply-all when asked.
- Thank once, not three times.

## 3. 履歴書
- 様式に従う。学歴は年月順で正式名称（「東京大学大学院 工学系研究科 化学生命工学専攻 博士後期課程 修了見込み」）。
- 職歴：雇用形態（長期インターン等）を明記。誇張しない。
- 志望動機・自己PR：結論 → 根拠（具体的経験・数字）→ 入社後の貢献。200〜300字程度。
- 本人希望記入欄：特になければ「貴社規定に従います。」。在留資格の変更が必要な点は面接で説明できるようにしておく。

## 4. 職務経歴書 / CV
- Reverse chronological. For each role: period, company, role, 2–5 bullets.
- Bullets: action verb + what + how (tools) + result (number/impact). "Built a GPU benchmark environment (Ollama, A100/H100/B200) measuring throughput, TTFT and concurrency; results informed the customer's GPU choice."
- Quantify where the profile gives numbers; never fabricate metrics.
- Skills grouped (Languages / ML / Infra / Chemistry tools); only skills with real usage.
- Confidential items (internal wiki, server paths, customer names under NDA) must not appear → `fact`/`confidential` issue.
- Length: CV 1–2 pages; 職務経歴書 A4 1–2 枚.

## 5. Cover letter / 志望動機 / form answers
- Answer exactly the question asked; respect character limits (count Japanese characters; HERP message ≤ 1000).
- PREP: Point → Reason → Example → Point (link back to the company).
- Avoid clichés without evidence ("コミュニケーション能力が高い", "passionate"); show it with an episode.
- Mention visa/start date facts briefly and positively.

## 6. Interview answers (written prep)
- 1 minute ≈ 300 Japanese characters / 130–150 English words.
- Start with the conclusion. Use 「御社」 (spoken). Prepare honest answers for gaps ("未経験ですが、〜が活きると考え、〜で学んでいます").

## 7. Severity guide
- high: wrong facts / fabricated claims, wrong company or person name, broken keigo toward the reader (e.g. 謙譲語 for the reader's actions), placeholders, confidential info, missing required element (attachment mentioned but not attached, no signature).
- medium: unnatural grammar, inconsistent style, too long, generic content, weak structure.
- low: wording polish, punctuation, minor consistency.
