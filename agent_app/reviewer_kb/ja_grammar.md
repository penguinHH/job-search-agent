# 日本語の文法・敬語チェックリスト（ビジネス文書・応募書類）

## 1. 敬語の基本
- 尊敬語は相手の行為、謙譲語は自分の行為。混同しない。
  - ✕「ご覧になってください」は可だが、✕「拝見してください」（相手に謙譲語）。
  - ✕「弊社にお伺いします」→ 相手先へ行くのは「御社に伺います」（「お伺いします」は二重敬語だが慣用として許容。迷えば「伺います」）。
- 二重敬語を避ける：✕「おっしゃられる」→「おっしゃる」、✕「ご覧になられる」→「ご覧になる」、✕「お見えになられる」→「お見えになる」、✕「御社様」→「御社」。
- 「させていただく」の多用を避ける。相手の許可や恩恵がない行為には使わない：✕「応募させていただきます」が続く文 → 1通に1〜2回まで、「応募いたします」に言い換える。
- 「〜のほう」「〜になります」「〜でよろしかったでしょうか」などのバイト敬語は使わない。
- 相手企業の呼び方：**書き言葉（メール・履歴書・ES・フォーム）は「貴社」**、話し言葉（面接・電話）は「御社」。自社・自分の所属は「弊社」ではなく学生は「私」「本学」「当研究室」。
- 人名＋「様」、役職名には「様」を重ねない：✕「部長様」→「部長」「〇〇部長」。宛名が部署なら「御中」、個人なら「様」（併用しない）。

## 2. 文法・表記
- 文体を統一：応募メール・書類は「です・ます」体。「だ・である」と混在させない。箇条書き内は体言止め可だが、同一リスト内で揃える。
- 主語と述語のねじれ：「私の強みは、〜できます」✕ →「私の強みは、〜できることです」。
- 「〜たり〜たり」は両方に付ける：✕「調べたり、実装しました」→「調べたり、実装したりしました」。
- ら抜き言葉：✕「見れる」「来れる」→「見られる」「来られる」。
- い抜き言葉：✕「〜してます」→「〜しています」（書き言葉）。
- 助詞の重複：「の」が3つ以上続かない（✕「研究室の先輩の論文の手法」）。「が」「は」の使い分け（新情報は「が」）。
- 一文は長くても60〜80字程度。読点で4つ以上つなぐ文は分割する。
- 漢字とひらがな：補助動詞・形式名詞はひらがな（「〜していく」「〜こと」「〜とき」「〜ください」「〜いたします」）。「頂く／いただく」：補助動詞は「いただく」。
- 数字：横書きは算用数字（2027年4月、3年間）。単位と数字の間を空けない。全角・半角を文書内で統一（英数字は半角が無難）。
- 外来語・技術用語は一般的な表記に（「インターフェース」「サーバー」など、文書内で統一）。英語の固有名詞は原綴りのまま（PyTorch、Docker）。
- 年号：西暦と和暦を混在させない（履歴書は様式の指定に従う）。

## 3. よくある誤用
- 「ご教授ください」→ 知識・方法を教えてほしいなら「ご教示ください」。
- 「取り急ぎ〜まで」は目上には避ける。
- 「了解しました」→「承知しました」「かしこまりました」。
- 「すいません」→「申し訳ございません」「恐れ入りますが」。
- 「参考になりました」→「勉強になりました」。
- 「各位様」→「各位」。
- 「〜させていただきたく存じます」は丁寧すぎて冗長になりやすい →「〜したく存じます」。

## 4. 外国籍・留学生として注意する表現
- 在留資格は正確に：「留学」「技術・人文知識・国際業務」「高度専門職」。「就労ビザ」は口語。書類では「就労可能な在留資格への変更」。
- 日本語能力は資格で客観的に：「JLPT N1（2022年取得）」。「ネイティブレベル」など主観的な表現は避ける。
